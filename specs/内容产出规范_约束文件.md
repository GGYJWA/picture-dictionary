## 总则：目标决定打法

我们当前处于**验证需求阶段**（非直接卖货）。所有内容以"测出真实市场反应"为先，转化话术后置。但叙事质量按爆款标准来——验证期也要写得像真人、不像 AI。

## 第一部分：选题逻辑链（以后出选题必走）

### 1. 提案式选题法（最高优先，解"后续发什么"）
从**用户为什么还没购买**出发，把每个购买阻力变成一个选题。五个阻力问题，每个写 5 个真实理由 = 25 个阻力 = 25 篇选题：
1. 用户为什么觉得自己不需要？
2. 用户为什么觉得可以自己解决？
3. 用户为什么选别人不选我？
4. 用户为什么不相信产品有价值？
5. 用户为什么现在不用买？

再问「我要让用户从什么判断，变成什么判断？」，每个阻力配一个提案观点。产出的是**带销售目标的内容选题**，不是模糊想法。

### 2. 卖点聚焦法（一篇只打透一个卖点）
卖点分三层，分配内容精力：
- **基础卖点**（用户默认该有）：排版、112条、有配图 → 可出现，不投入大量内容
- **决策卖点**（真正影响购买）：中英双版直接粘、网站大白话搜索、8本书翻译 → 反复讲
- **差异卖点**（同行少有）：配套网站、持续更新、NFC钥匙扣 → 重点打

铁律：**卖点是产品语言，选题要翻译成用户语言**。禁止拿"逐字稿/词条数"这种名词直接造标题，要问：这个卖点解决用户什么问题？用户在什么场景意识到它重要？没有它会有什么麻烦？

### 3. 里程碑选题法 / Build in Public（验证期主力）
把产品从诞生到迭代的"有效变化"变成内容。**优先小里程碑**：第一次有人问某问题、第一次因反馈改产品、词典新增词条、NFC 进展、价格调研结果。让"验证需求"的过程本身成为选题——不等有成果才发。

### 4. BERT 搜索选题法（补搜索流量）
从一个核心搜索词还原用户背后的任务/场景/人群/上下游，覆盖不同搜索表达。用户搜 A、内容可以是语义相关的 B。核心词示例："AI画图描述不出来"→ 任务/场景/人群/上下游各展开。出单笔记大多来自搜索流量，标题和正文前100字要自然布局搜索词。

### 5. 观点选题法（起 IP 用）
有观点才涨粉。把传播广的观点**迁移到我们的具体领域**，形成可反复强化的账号观点（"工具会过时，认出画面的能力不会""别再收藏提示词了"）。

## 第二部分：笔记编写逻辑链（写笔记必走）

1. **先读对标库**（写死，不可跳过）：`~/.workbuddy/skills/xhs-note-writer/references/benchmark-samples.md`。对标库是动态的——用户刷到好笔记就往里加，越用越准。
2. **每篇对标不同样本**：9篇样本=9种叙事策略，多篇不可重复套同一模板。"伤其十指不如断其一指"——把一篇对标吃透成完整叙事模型，胜过六篇综合（综合=平均值=四不像）。
3. **叙事主语"我"**：禁止"你有没有/你大概经历过"开头（AI味最重）。"你"只在后半段自然出现。
4. **去 AI 味靠样本不靠规则**：堆"不要有AI味"的指令没用，靠喂高质量参考样本。
5. **标题严格 18-20 字**（含标点emoji）：从痛点/对比/教程/避坑/省钱角度切入。之前 25-30 字的候选以后一律重写。
6. **一篇只打透一个卖点**，把卖点翻译成用户问题。
7. **对比句式"不是A而是B"**：我们的核心武器，保留（手册里"课件批量提示词"说避免该句式，那是针对课件罗列场景，不适用于我们）。
8. **口语化衔接＋具体数字＋段落1-3句空行**。
9. **零容忍 AI 句式**：在当今/值得注意的是/综上所述/不仅而且/随着发展/在XX时代。

### 每篇自查清单（逐条勾选才交付）
- [ ] "我"开头，非"你有没有"？
- [ ] 对标了具体样本、多篇不重复？
- [ ] 标题 18-20 字？
- [ ] 一篇只讲一个卖点、且翻译成了用户问题？
- [ ] 至少一处"不是A而是B"？
- [ ] 具体数字、口语化衔接？
- [ ] 零 AI 句式？
- [ ] 读起来像真人在讲自己的事？
- [ ] 验证期 CTA 是征集/投票，非下单？
- [ ] 合规：无下单/客服/外链/价格锚；NFC 只写"即将上线+优惠获取"；词典说 112 条现货、更新不承诺时间？

## 第三部分：封面图逻辑（重要纠偏）

手册明确：**AI 生成的封面图基本没流量，美观不重要，真实性/场景性才重要**。四种推荐法：平板实拍、实物打印拍摄、飞书文档截图、twitter 截图。

**约束**：
- 笔记**首图**（决定点击）优先用**真实场景图**：词典打印实拍、网站真实界面截图、两张真实出图对比；
- 我做的陶阿狗风 AI 大字图（主图1-5）留作**内页/详情页**，不作为首图；
- 需要实物时，我给拍摄脚本和后期模板，实物由用户拍。

## 第四部分：后续扩写方向（内容/产品，非第8/9章书籍扩充）

沿用户成长路径设计商品矩阵（让用户每走一步都有下一个解决方案）：
- 完全小白 → 轻量入门版/免费钩子（"30个最常用画面词"）
- 想快速查 → 网站＋关键词速查卡
- 想系统学 → 第8/9章（已规划）＋ 光影/构图专题小册
- 想真会认 → 练习型产品（看图认词互动/测试）
- 深度用户 → 社群/陪跑（"指南+社群"是低转高策略）

手册提醒：从**旧流程改造**入手（我们=小白抄散词→出图不对→词典改造这个流程），方向已对；"万物皆可指南"与我们契合。
