# 配图自检规范（每次生成必做）

- 日期：2026-11-18
- 要求来源：用户明确要求——每次生成配图都要做一遍自检，确保图片没有问题
- 适用：全书所有配图（A/B 对比图、单图）

## 一、为什么必须自检

实测已证明：文生图模型会"偷偷改主体"（加胶片颗粒结果换了张脸）、"连带改场景"（加体积光把走廊改了）。只看 prompt 不看成图，会把错误配图收进书里，误导读者。

## 二、每张图生成后的自检清单

用看图工具实际打开图，逐项确认：

1. **主体是否正确**：是不是该出现的对象？有没有换脸、换物、多出肢体？
2. **变量是否生效**：目标词的效果出来了吗？（如拉丝纹、光柱、金黑配色）
3. **控制变量是否干净**：A/B 对比图里，除了目标变量，其他（主体、构图、背景）是否保持一致？若被污染，标记并改用图生图重做。
4. **有无AI瑕疵**：畸形五官、扭曲文字、水印、多余元素。
5. **风格是否符合词条**：风格类图是否真的像该流派，而非四不像。
6. **标注是否到位**：确认配图标注"示意图·仅供参考"。

## 三、自检结果处理

- ✅ 通过 → 收录，登记到配图对应表。
- ⚠️ 变量生效但主体/场景被污染 → 用图生图锁基准重做（实测有效解法）。
- ❌ 未生效或严重瑕疵 → 调整 prompt 重生成一次。
- 每次自检结果记入配图日志，便于追溯。

## 三·补 水印处理（用户已确认：本地抹掉）

出图工具会在右下角强制加"AI生成 / WORKBUDDY"角标，生成参数无法关闭。用户确认本地去除。

**已验证方案（sips 裁剪，无需安装第三方库）：**
```
sips -c 890 1024 原图.png --out 去水印/图名.png
```
- 从 1024×1024 裁掉底部 134px → 1024×890，水印（含"AI生成"和"WORKBUDDY"）彻底去除。
- 人像主体在中上部，裁剪不伤脸和构图；横向比例更适合电子书。
- 实测：硬光/柔光/逆光/底光 4 张全部验证水印消失、主体完整。
- 注意：裁 55px 会残留"WORKBUDDY"、裁 100px 会残留"AI生成"，**必须裁 134px（保留 890 高）**。
- 处理后存到 `测试样张/去水印/` 子目录，书里用去水印版。配图仍用文字标注"示意图·仅供参考"说明其为示意。

> 环境备注：pip/npm 安装被沙箱 SIGTERM 拦截，Pillow/sharp/ffmpeg 均不可用；sips 为系统自带、可用。故采用 sips 裁剪方案。

## 四、工艺规则（配合实测三条铁律）

- 材质类 → 纯文生图（主体稳定）
- 氛围/画质类 → 图生图锁基准（防换主体）
- 风格类 → 纯文生图（风格本就要重构整图）

## 五、配图分级策略（用户已确认）

- 光影/色彩/氛围（1、5、7章）→ A/B 对比图
- 构图/风格（3、4章）→ 单图为主
- 纹理材质（6章）→ 单图
- 全书导读 → 1 组"用 vs 不用"钩子图
