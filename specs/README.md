# 规范文件主副本（specs/）

本目录是《把画面说给AI听》的**权威规范源云端主副本**，用于抗删除、防产出偏离。

## 文件清单
- `白皮书_制作规范_约束文件.md` —— **唯一权威规范源**，九章，含第八章交付清单、第九章抗删除机制
- `暗门设计_文风指纹规则.md` —— 文风指纹（版权暗门）三句式规则
- `配图自检规范.md` —— 配图六项自检 + 去水印工艺
- `扩充大纲_第8-9章.md` —— 后续扩充计划（第8章视觉原理12条、第9章绘画流派14条，已定案，待执行）
- `build_ebook.py` —— 电子书生成器（含陶阿狗风排版、打印样式、base64内嵌、微像素封面）
- `build_web.py` —— 网页数据生成器（Markdown→data.json + 配图）
- `build_ima_structure.py` —— ima 检索版生成器
- `detect_overflow.py` —— PDF 溢出检测（导出前必跑，须输出「✅ 无溢出」）

## 恢复流程（本地文件被删时）
1. 从本目录拉取全部文件到本地工作区根目录（约束文件等放根，生成器放根，配图自检规范放 `白皮书实测/`）
2. 读 `白皮书_制作规范_约束文件.md` 全文，尤其第二章（写作要求）、第五章（PDF规范）、第九章（抗删除机制）
3. 核对 ima 知识库 `画面提示词`（ima_kb_M6Ibw5sE）的规范摘要副本
4. 恢复完成才继续产出，严禁凭记忆自行发挥

## 每次开工前必做
读约束文件 + 对应章节配图索引 + 文风指纹规则，核对后再动笔。

## 交付自检
见约束文件第九章 9.5 节清单，逐条勾选才交付。
